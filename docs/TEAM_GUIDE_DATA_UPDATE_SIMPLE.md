# 📊 Updating Match Data - Simple Guide

## For Coaching Staff

---

## 🚀 Quick Steps

### 1️⃣ Run Scraping Script
```bash
python3 src/data_processing/scrape_all_concacaf_matches.py
```

### 2️⃣ Update Streamlit
**Choose one:**
- ⏰ **Wait 5 minutes** (automatic)
- 🔄 **Click "Update Data" button** (immediate)

### 3️⃣ Done! ✅
New data appears in the app.
